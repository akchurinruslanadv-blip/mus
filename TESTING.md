## 2. Как запустить автоматический набор тестов

В папке `tests/` подготовлен скрипт проверки всей цепочки:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\Admin\Desktop\musik-project\tests\test_fetcher.ps1"
```

### Набор проверок в скрипте:
1. Проверка наличия бинарников `yt-dlp.exe` и `deno.exe`.
2. Проверка отклика и версий утилит.
3. Проверка резолвинга аудиопотока YouTube без скачивания (dry-run).
4. Проверка целостности и размера скачанных файлов в `/dynamic`.
