# Развертывание musik на ультра-легком VPS (1 vCPU / 1 GB RAM / 5 GB Disk)

Данный профиль оптимизирован для работы на самых доступных тарифах виртуальных серверов (от 1-2€ в месяц).

---

## 📊 Потребление ресурсов

| Компонент | RAM (Память) | Диск (HDD/SSD) | Назначение |
| :--- | :--- | :--- | :--- |
| **ОС (Ubuntu 22.04 / Debian 12 minimal)** | ~80 МБ | ~1.1 ГБ | Базовая система |
| **Go Core Player** (порт 8786) | ~45 МБ | ~35 МБ | Ядро воспроизведения и SQLite |
| **Deno Hybrid Gateway** (порт 8787) | ~75 МБ | ~95 МБ | Веб-интерфейс, прокси, каталог |
| **ONNX Embedder** (порт 8790) | ~80 МБ | ~45 МБ | Нейросетевые 512D эмбеддинги (без PyTorch!) |
| **SQLite DB** (каталог 3.27 млн треков) | ~40 МБ | ~650 МБ | Индексированная база данных |
| **Динамический кэш треков (LRU)** | — | До 1.0 ГБ (~300 треков) | Автоматически очищается при заполнении |
| **ИТОГО** | **~320–480 МБ** | **~2.9 ГБ из 5.0 ГБ** | **Запас RAM: >500 МБ, Диск: >2.1 ГБ** |

Дополнительно автоматически создается **1 ГБ swap-файл** с `vm.swappiness=10` для гарантированной защиты от Out-Of-Memory.

---

## 🚀 Вариант 1: Быстрая установка в 1 команду (Native Systemd — Рекомендуется)

Подходит для любого чистого сервера **Ubuntu 22.04 / 24.04** или **Debian 11 / 12**.

1. Подключитесь к вашему серверу по SSH:
   ```bash
   ssh root@YOUR_SERVER_IP
   ```

2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/akchurinruslanadv-blip/mus.git /opt/musik
   cd /opt/musik
   ```

3. Запустите автоматический установщик:
   ```bash
   sudo bash scripts/deploy_vps_1gb.sh
   ```

Скрипт автоматически:
* Создаст 1GB Swap;
* Установит Deno, yt-dlp, FFmpeg;
* Настроит изолированное окружение ONNX Runtime;
* Скомпилирует и запустит 3 systemd-сервиса (`musik-player`, `musik-embedder`, `musik-gateway`);
* Включит автозапуск при перезагрузке сервера.

Плеер будет доступен в браузере по адресу:
👉 `http://YOUR_SERVER_IP:8787`

## 🐳 Вариант 2: Запуск в Docker Compose

Если вы предпочитаете контейнеризацию:

```bash
docker compose -f docker-compose.vps-1gb.yml up -d --build
```

---

## 🛠 Управление сервисами

* Проверить статус всех служб:
  ```bash
  systemctl status musik-gateway.service musik-player.service musik-embedder.service
  ```
* Перезапустить шлюз:
  ```bash
  systemctl restart musik-gateway.service
  ```
* Просмотр логов в реальном времени:
  ```bash
  journalctl -u musik-gateway.service -f
  ```

## 🍪 Настройка YouTube Cookies (при необходимости)

Если YouTube начинает требовать проверку от ботов:
1. Поместите экспортированный `cookies.txt` в корневую директорию проекта `/opt/musik/cookies.txt`.
2. Сервер подхватит его на лету без перезапуска.
