# 🎵 musik — Умное Self-Hosted Нейро-Радио & Музыкальный Сервер

> **Основа проекта:** Этот проект вдохновлён и создан как надстройка над оригинальным self-hosted плеером **[musik](https://github.com/torwin-job/musik)** от автора **[torwin-job](https://github.com/torwin-job)**.  
> 
> Оригинальный `musik` задуман как приватный, быстрый и надёжный сервер для воспроизведения собственной локальной коллекции аудиофайлов (MP3, FLAC), не требующий зависимости от внешних облаков.
> 
> Настоящее расширенное издание развивает эту концепцию в сторону **гибридного нейро-радио**: мы сохранили бережное отношение к локальным файлам, добавив возможность на лету открывать новую музыку через On-Demand стриминг, миллионный акустический каталог и двухуровневый каскад рекомендаций (12D + 512D CLAP). Все новые функции работают как внешний сайдкар по принципу **Zero-Intrusion Architecture**, сохраняя оригинальное Go-ядро в полной неприкосновенности.

## ✨ Ключевые возможности надстройки

### 1. 🎛️ Регулятор «Баланс открытий» и Класс `CustomAudioSlider`
* **Плавная регулировка радиопотока:**
  - `0%` — ❤️ **Только любимое:** воспроизводятся проверенные треки из ваших лайков.
  - `50%` — ⚖️ **Баланс 50 / 50:** гармоничное чередование знакомых композиций и новых открытий.
  - `100%` — 🚀 **Только новые открытия:** поток формируется исключительно из внешнего каталога (3.27 млн треков) под ваш акустический профиль.
* **Модульная архитектура компонентов (`CustomAudioSlider`):**
  - Экспортирован в `window.CustomAudioSlider`.
  - Легковесный vanilla JS класс с инкапсулированной версткой, `localStorage`-персистентностью, живыми бейджами и коллбэками. Позволяет добавлять любые будущие регуляторы параметров в одну строчку.

### 2. 🎛️ Акустический эквалайзер вкуса (12D Vector Steering)
В панель очереди радио встроен интерактивный блок с четырьмя регуляторами смещения рекомендательного вектора:
* ⚡ **Драйв / Энергия (`energy`):** от спокойного медитативного чилла (-50%) до взрывного рейва/рока (+50%).
* 🎭 **Вайб / Настроение (`valence`):** от меланхоличного нуара (-50%) до солнечной эйфории (+50%).
* 🎸 **Звучание (`acousticness`):** от синтетического электронного саунда (-50%) до живых инструментов и рояля (+50%).
* ⏱️ **Темп (`tempo`):** от замедленного бита (-30%) до скоростного ритма (+30%).
* Кнопка **«↺ Сбросить в 0»** моментально возвращает радио в нейтральный автопилот. Все настройки сохраняются в SQLite для каждого устройства.

### 3. ⚡ Двойной Zero-Stall буфер переключения (0 мс задержки)
* Алгоритм формирования очереди радио всегда поддерживает на диске как минимум **два готовых следующих трека** (`queue[0]` и `queue[1]`).
* Даже при быстром двойном переключении треков пользователь не сталкивается с паузой на скачивание — треки играют моментально за **0 мс**.
* Фоновый планировщик заблаговременно прогревает последующие позиции очереди (`queue[2]`, `queue[3]`).

### 4. 🏷️ Прозрачные бейджи источников треков
На **главном экране Now Playing** и в **очереди радио** отображается происхождение каждой композиции:
* `🧠 512D Вектор` — подобран нейросетью CLAP по семантическому тембральному сходству.
* `⚡ 12D Каталог` — отобран из каталога 3.27 млн треков по акустическим характеристикам.
* `❤️ Избранное` — трек из ваших сохранённых лайков.
* `💾 Закреплено` — трек сохранён навсегда на диск и защищён от автоочистки кэша.
* `📁 <Имя плейлиста>` — трек принадлежит пользовательскому плейлисту.
* `📥 Импорт` — поступил из пакетного файла плейлиста.
* `💿 Локальный` — аудиофайл из локальной коллекции.

### 5. 🧠 Двухуровневая рекомендательная система (12D + 512D)
* **Мгновенный акустический отклик (12D):** Выборка кандидатов по 12 параметрам из базы на 3.27 млн треков выполняется за **42 мс** благодаря оптимизированному кластерному сканированию.
* **Глубокий акустический вкус (512D CLAP):** Модель `laion/larger_clap_music_and_speech` строит 512-мерный вектор восприятия музыки человеком.
* **Микро-демон ONNX Runtime (`embedder_onnx.py`):** Альтернативный легковесный инференс для VPS, требующий всего **~45 МБ диска** и **~80 МБ ОЗУ** (вместо 2.2 ГБ PyTorch).

### 6. 💾 Умный адаптивный LRU-кэш с защитой закреплений
* **Автоматическая ротация:** Кэш удерживается в пределах лимита (настраивается: 1 ГБ для VPS, 3 ГБ по умолчанию), мягко освобождая место от редко прослушиваемых треков.
* **Разделение Любимое (`♥`) vs Закрепленное (`💾`):**
  - `♥` **Избранное:** Формирует вкусовой профиль радио, может быть вытеснено из локального кэша при нехватке места и подгружено заново при необходимости.
  - `💾` **Закреплено навсегда:** Полный иммунитет к ротации, гарантированное постоянное наличие на диске.

### 7. 📜 Неограниченная история прослушивания (25 мс)
* Доступна во вкладке **⏮ Прослушано** в боковой панели.
* **Индексированный SQLite-запрос (25 мс):** Оптимизированные предикаты позволяют возвращать тысячи треков без задержек.
* **Виртуальный скролл и живой поиск:** Рендеринг порциями по 50 элементов исключает нагрузку на браузер.
* **Быстрое повторное воспроизведение:** Запуск любого ранее прослушанного трека в 1 клик.

### 8. 💔 Интерактивное управление дизлайками
* Если трек был случайно отмечен дизлайком, отметку можно снять прямо из интерфейса или через API (`POST /api/v1/tracks/:id/undislike`).
* Кнопка дизлайка остаётся активной и кликабельной, позволяя легко переключать статус.

### 9. 🛡️ Music & Speech Guard: Защита от разговорного аудио
* **Контроль хронометража:** Отсечение коротких звуковых фрагментов (< 40 с) и многочасовых записей (> 12 мин).
* **Порог речевой активности (`speechiness`):** Каталог фильтруется по уровню `speechiness <= 0.35`.
* **Фильтрация поисковых запросов:** Запросы снабжаются музыкальными директивами, автоматически исключая подкасты, интервью и аудиокниги.

### 10. 🛡️ Zero-Intrusion Архитектура
* Исходный код оригинального Go-плеера в `musik-main/` остаётся на 100% нетронутым.
* Deno Sidecar Gateway прозрачно взаимодействует с ядром через стандартные HTTP API и файловую систему.

## 🚀 Варианты развертывания

### Вариант А: Развертывание на ультра-легком VPS (1 vCPU / 1 GB RAM / 5 GB Disk)
Подробное руководство находится в [README_DEPLOY_VPS.md](file:///c:/Users/Admin/Desktop/musik-project/README_DEPLOY_VPS.md).

Быстрая установка на чистый Ubuntu/Debian сервер в одну команду:
```bash
git clone https://github.com/akchurinruslanadv-blip/mus.git /opt/musik
cd /opt/musik
sudo bash scripts/deploy_vps_1gb.sh
```

Или через Docker Compose:
```bash
docker compose -f docker-compose.vps-1gb.yml up -d --build
```

---

### Вариант Б: Локальный запуск на рабочей станции

#### Требования
* **Deno:** 1.40+ (встроен в `bin/` или системный)
* **Python:** 3.10+ (с `torch` для полного режима или `onnxruntime` для легковесного)
* **FFmpeg** и **yt-dlp**

#### Запуск одной командой (Windows)
```powershell
.\scripts\start_all.ps1
```
Сервер запустит необходимые службы и откроет плеер по адресу:
👉 **http://127.0.0.1:8787/**

#### Запуск (Linux / macOS)
```bash
chmod +x scripts/*.sh
./scripts/start_all.sh
```

## 📡 REST API расширения

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/radio/settings` | Получить настройки радио (`discoveryRatio`, акустические смещения) |
| `POST` | `/api/v1/radio/settings` | Обновить баланс радио и параметры смещения вкуса |
| `GET` | `/api/v1/radio/history` | Неограниченная оптимизированная история прослушивания (25 мс) |
| `POST` | `/api/v1/tracks/:id/undislike` | Снять отметку дизлайка с трека |
| `GET` | `/api/v1/tracks/:id/origin` | Получить происхождение одного трека (512D, 12D, плейлист, избранное) |
| `POST` | `/api/v1/tracks/origins` | Пакетный запрос происхождения треков |
| `GET` | `/api/v1/cache` | Статистика кэша: занятый объём, лимит, количество 512D векторов |
| `POST` | `/api/v1/cache/clean` | Ручной запуск очистки временного кэша |
| `POST` | `/api/v1/tracks/:id/pin` | Закрепить трек навсегда на диске (иммунитет к LRU-очистке) |
| `DELETE` | `/api/v1/tracks/:id/pin` | Открепить трек от постоянного хранения |
| `POST` | `/api/v1/import/playlist` | Запустить фоновый импорт текстового плейлиста |
| `GET` | `/api/v1/import/status` | Сводный статус воркера очереди импорта |
| `GET` | `/api/v1/import/items` | Список треков очереди импорта с пагинацией и фильтрацией |
| `POST` | `/api/v1/import/unfavorite` | Снять отметку «Избранное» со всех импортированных треков |
| `POST` | `/api/v1/catalog/blend` | Поиск 12D кандидатов в каталоге (3.27M+) по акустическим свойствам |
| `POST` | `/api/v1/catalog/preindex-512` | Фоновый 512D-майнинг топ-рекомендаций под персональный вкус |
| `POST` | `/api/v1/tools/update-ytdlp` | Фоновое обновление бинарника yt-dlp до актуальной версии |
