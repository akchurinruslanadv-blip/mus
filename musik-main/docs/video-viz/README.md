# Слайды для видео — шпаргалка

Открой в браузере: `docs/video-viz/index.html`
Полный экран: **F**. Листать: **→ / Space**.
Автопоказ для записи экрана: **A** — переход к следующему слайду каждые 11,5 секунды; повторное нажатие останавливает. Клик мышью тоже перелистывает.

Анимации запускаются заново при каждом открытии слайда. На слайде с графиками сначала появляются оси, затем прорисовываются два вектора, дуга угла и только после этого считаются коэффициенты `0,81` и `0,32`. При перелистывании элементы исчезают в обратном порядке примерно за две секунды: пояснения → карточки/график → заголовок → плашка раздела.

## Озвучка для слайда «Единичная длина»

«Когда я говорю, что длина вектора равна единице, это не значит, что вся песня превратилась в число один. Внутри по-прежнему остаются 512 разных чисел. Единица — это их общая длина: берём квадраты всех координат, складываем и извлекаем корень. Затем делим каждую координату на получившуюся длину. Вектор становится короче или длиннее, но продолжает смотреть в ту же сторону. Благодаря этому при сравнении мы оцениваем именно характер звучания, а не случайный масштаб чисел.»

## Важное уточнение для озвучки

Не говори «похожи на 32 процента». Корректно: «коэффициент косинусного сходства равен 0,32». Сам по себе 0,32 не является универсальным порогом. Вывод появляется в сравнении: у близкого трека из этой же библиотеки коэффициент около 0,81, а у выбранной далёкой пары — 0,32.
