# 📖 Руководство пользователя: Умное Нейро-Радио

Полное практическое руководство по интерфейсу и возможностям плеера.

---

## 1. Главный экран плеера (Now Playing)

Когда играет музыка, на экране отображается:
* **Обложка, Название и Артист трека.**
* **Плашка «Источник»** (прямо под именем артиста):
  - Показывает, почему заиграл этот трек:
    - `❤️ Избранное` — трек из ваших лайков.
    - `💾 Закреплено` — сохранён на диске навсегда.
    - `🧠 512D Вектор` — подобран нейросетью CLAP по акустическому тембру и настроению.
    - `⚡ 12D Каталог` — взят из внешнего каталога 81k треков.
    - `📁 <Имя плейлиста>` — из вашего плейлиста.
    - `📥 Импорт` — из загруженного вами файла.
    - `💿 Локальный` — ваш файл с жесткого диска.
* **Кнопки управления в плеере:**
  - `▶ / ⏸` — Воспроизведение / Пауза (или пробел на клавиатуре).
  - `⏭` — Следующий трек (клавиша `N`).
  - `♥` — Добавить в Избранное (влияет на радио, но файл может удалиться при нехватке места).
  - `💾` — **Закрепить навсегда на диске** (сохраняет песню в `favorites/`, файл **никогда не удалится** при автоочистке кэша).

---

## 2. Панель очереди и Баланс открытий (справа)

В правой колонке плеера расположены:
1. **🎛️ Ползунок «Баланс открытий (радио)»:**
   - Позволяет управлять составом радио:
     - `0%` — Только любимое (радио крутит только треки с лайком).
     - `50%` — Баланс 50 / 50 (половина эфира — любимое, половина — новые открытия).
     - `100%` — Только новые треки (поток формируется исключительно из неизведанных песен каталога 81k под ваш акустический вкус).
   - Положение ползунка сохраняется автоматически в вашем браузере и на сервере.
2. **Вкладка «⏭ Очередь»:**
   - Список ближайших треков, которые радио запланировало для воспроизведения.
   - Рядом с каждым треком отображаются значки источников (`♥`, `🧠 512D`, `⚡ 12D`, `📥`).
3. **Вкладка «⏮ Прослушано» (История):**
   - Полный неограниченный список всех прослушанных треков.
   - Вверху расположена строка мгновенного поиска `🔍 Найти в истории...` (можно искать по названию, артисту или тегам `512`, `12`, `избранное`).
   - Клик по любому треку из истории мгновенно запускает его заново.
   - Список загружается порциями по 50 треков и не тормозит браузер.

## 3. Вкладка «Загрузка» (Импорт файлов и Управление кэшем)

В верхнем меню выберите раздел **«Загрузка»**:
1. **Индикатор умного кэша 3 ГБ:**
   - Показывает, сколько места занимают треки в кэше и сколько 512D векторов рассчитано.
   - Кнопка `Очистить временное аудио` позволяет безопасно освободить место (закреплённые `💾` треки не удаляются!).
2. **Импорт плейлистов из файлов:**
   - Кнопка **`📁 Загрузить файл со списком (.txt, .m3u)`** — откроет стандартный проводник, где можно выбрать файл со смартфона или компьютера.
   - Либо просто вставьте список треков в текстовое поле.
   - Опции перед импортом:
     - *«Добавить в Избранное ❤️»*
     - *«Сохранить навсегда на диск 💾»*
     - *«Сразу запустить 512D векторизацию в фоне»*
3. **Интерактивный эксплорер очереди импорта:**
   - Под прогресс-баром расположена интерактивная таблица всех загруженных треков (например, всех 2003 треков из вашего файла).
   - Вкладки для быстрой фильтрации:
     - `Все` — полный список.
     - `✓ Готовы` — треки, которые уже скачаны и векторизованы.
     - `⟳ В процессе` — трек, который скачивается или оцифровывается прямо сейчас.
     - `⏳ В очереди` — ожидающие обработки.
     - `✕ Ошибки` — треки, которые не удалось найти.
   - Поиск по списку очереди в реальном времени.
4. **Кнопка исправления баланса радио:**
   - **`💔 Снять отметку ❤️ с импортированных треков`** — если при импорте файла случайно отметились тысячи треков как избранные, эта кнопка в 1 клик снимет с них лайки, вернув радио свободу выбора. Сами песни останутся в вашей базе.

---

## 4. Проверка с мобильного телефона или другого устройства

Если вы открываете плеер по ссылке в локальной сети или через интернет:
1. Откройте адрес: **`http://<IP-сервера>:8787/`** (например, `http://78.17.19.244:8787/`).
2. При первом входе обновите страницу (Ctrl+F5 на ПК или свайп вниз на телефоне), чтобы загрузить актуальную версию скрипта `v2.5.0`.
3. Все элементы адаптированы под мобильные экраны и сенсорное управление.
