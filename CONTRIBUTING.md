# Руководство по участию в разработке (Contributing Guide)

Мы приветствуем вклад в развитие проекта умного нейро-радио! Чтобы проект оставался стабильным, чистым и надежным, просим соблюдать следующие правила архитектуры и стандарты кода.

---

## 🏛️ Ключевой архитектурный принцип: Zero-Intrusion

1. **Никаких изменений в `musik-main/`:**
   - Папка `musik-main/` — это апстрим оригинального плеера [torwin-job/musik](https://github.com/torwin-job/musik).
   - Мы **никогда не изменяем и не коммитим** изменения в оригинальное Go-ядро.
   - Любой новый функционал разрабатывается исключительно в папке `extensions/fetcher/` как независимый Sidecar-модуль.
2. **Изоляция и обратная совместимость:**
   - Если Sidecar отключен, оригинальный плеер Go Core должен продолжать работать в обычном локальном режиме без ошибок.
   - Любые расширения веб-интерфейса подключаются динамически через инжектор скрипта `/addon/ui.js`.

---

## 🛠️ Стек технологий

* **Sidecar Gateway:** Deno 2+ (TypeScript). Без внешних npm-пакетов, только стандартная библиотека Deno и `@db/sqlite`.
* **Нейросетевой модуль:** Python 3.10+ (`torch`, `torchaudio`, `transformers`, `librosa`).
* **База данных:** SQLite (WAL-режим, строгие индексы, запросы с предикатами `EXISTS` для мгновенного отклика).
* **Фронтенд-расширения:** Vanilla JavaScript (ES2022+), нативный DOM API без фреймворков.

---

## 🧪 Разработка и запуск тестов

Перед отправкой изменений обязательно убедитесь, что:
1. **Все тесты проходят успешно:**
   ```bash
   deno test --allow-all extensions/fetcher/tests
   ```
2. **TypeScript компилируется без единого предупреждения:**
   ```bash
   deno check extensions/fetcher/src/*.ts scripts/*.ts
   ```
3. **Нет синтаксических ошибок в JavaScript:**
   ```bash
   deno eval "await import('./extensions/fetcher/src/ui_overlay.js')"
   ```

---

## 📋 Правила оформления коммитов и PR

* Структурируйте коммиты по смыслу (например, `feat(radio): add mood drift parameter`, `fix(cache): resolve race condition in LRU purge`).
* Не коммитьте бинарные файлы (`bin/`), базы данных (`*.db`), аудиофайлы (`dynamic/`, `*.mp3`) и временные логи.
* Добавляйте юнит-тесты на новую бизнес-логику в папку `extensions/fetcher/tests/`.
